# 100 Days of Building

I am committing to building something every day for 100 days to improve as a software engineer.

## Goals

- Build real projects
- Improve JavaScript and React
- Learn backend development
- Practice problem solving
- Improve Git and GitHub workflow
- Build a portfolio for internships and freelancing

## Rules

1. Build something every day.
2. Make at least one meaningful commit.
3. Document what I learned.
4. No zero days.
5. Finish projects before chasing new technologies.
